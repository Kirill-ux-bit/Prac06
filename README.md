## Вопросы на осмысление
1) Windows получает сведения о процессоре, дисках и USB‑устройствах от драйверов устройств, из реестра системы,  а также через WMI - при этом прямое обращение к устройству не всегда требуется, так как данные могут браться из уже сформированных системных структур.
2) Доступ к оборудованию не включили в .NET по умолчанию из‑за нишевой востребованности, сильной зависимости от Windows (WMI), стремления к модульной архитектуре, в то время как Console.WriteLine - универсальная, простая и кроссплатформенная функция.
3) Сведения, предоставляемые WMI, динамичны - они обновляются в реальном времени при изменении конфигурации оборудования (например, при подключении флешки) без перезапуска системы или программ.
4) Это говорит о наличии общего системного источника данных (например WMI) к которому обе программы обращаются через стандартные API Windows.
